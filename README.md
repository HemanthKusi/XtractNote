# XtractNote

**AI-powered YouTube to content converter** — multi-agent blog, notes, summary, and research generator.

XtractNote uses a LangGraph multi-agent pipeline to transform YouTube videos into structured, beautifully formatted content. Paste a YouTube link, choose a format, and the agent pipeline handles the rest.

## Architecture

```
Frontend (Next.js + React)  ←→  Backend (Python + FastAPI + LangGraph)  ←→  Supabase (Auth + DB)
```

- **Frontend:** Next.js 16, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Python 3.13, FastAPI, LangGraph, LangChain
- **Database:** Supabase (PostgreSQL + Auth + Storage)
- **AI:** OpenAI / Anthropic Claude (swappable via env variable)

## Getting Started

### Prerequisites

- Node.js 18+ (`node --version`)
- Python 3.13 (`python --version`) — not 3.14, which has no `pydantic-core` wheels
- Git (`git --version`)
- A Supabase account (free at supabase.com)
- An OpenAI or Anthropic API key (at least one)

### Setup

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/xtractnote.git
cd xtractnote

# 2. Set up the frontend
cd frontend
npm install
cp .env.example .env.local
# Edit .env.local with your Supabase keys
cd ..

# 3. Set up the backend
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your keys
cd ..

# 4. Start both servers
# Terminal 1 — Frontend (http://localhost:3000)
cd frontend && npm run dev

# Terminal 2 — Backend (http://localhost:8000)
cd backend && source .venv/bin/activate && uvicorn app.main:app --reload --port 8000
```

### Environment Variables

Copy `.env.example` from the root to:
- `frontend/.env.local` (frontend variables start with `NEXT_PUBLIC_`)
- `backend/.env` (backend variables — includes secrets)

See `.env.example` for all required values.
